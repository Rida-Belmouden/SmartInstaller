# SmartInstaller

A modern Windows package manager inspired by Ninite.

## Tech Stack

- .NET 10
- ASP.NET Core MVC
- ASP.NET Core Web API
- WPF
- Entity Framework Core
- SQL Server LocalDB

## Solution Structure

```
src/
    SmartInstaller.Web
    SmartInstaller.Api
    SmartInstaller.Agent
    SmartInstaller.Core
    SmartInstaller.Data
    SmartInstaller.Services

tests/
    SmartInstaller.Tests
```
